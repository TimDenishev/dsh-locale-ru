# dsh-locale-ru

⚠️ **Не нужен с DSH 0.2.2-rc.1: русский язык интерфейса встроен в приложение.**

Начиная с 0.2.2-rc.1 официальные пакеты DSH содержат русские словари (`ru`) для интерфейса, а встроенный плагин локали сам добавляет «Русский» в Настройки → Общие → Язык.

Ставить этот плагин на 0.2.2-rc.1 и новее не нужно: он пытается зарегистрировать язык `ru` повторно и роняет старт веб-клиента — `web boot: 1 entry did not activate`, `dsh-locale-ru: failed`.

Репозиторий остаётся как история русификатора для DSH 0.2.1 и старше. Инструкция по установке для тех версий — в истории файла (кнопка **History** у README). Свежий перевод для 0.2.2 и новее живёт в самих пакетах DSH.

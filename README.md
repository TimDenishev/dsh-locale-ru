# dsh-locale-ru

Русский язык интерфейса для настольного приложения **DeepSeek Harness (DSH)**.

После установки в «Настройки → Общие → Язык» появляется «Русский».

## Что переведено

- 2 570 строк интерфейса в 57 разделах: чат, настройки, модели, плагины, расписание, файлы, терминал, голосовой ввод и др.
- Не переведены: системные промты, документация и строки, которых нет в версии 0.2.0-rc.2. Они показываются по-английски.

Проверено на DSH 0.2.0-rc.2.

## Установка

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP**, распакуйте.
2. Положите папку `dsh-locale-ru` в постоянное место, например
   `C:\Users\<ваше имя>\dsh-plugins\dsh-locale-ru`.
   Потом её не удаляйте и не переносите: DSH берёт перевод оттуда.
3. В DSH слева нажмите **Plugins → Add plugin**.
4. Вставьте полный путь к папке и нажмите **Install**.
5. Если появится **Enable now**, нажмите. Если приложение напишет, что плагин загрузится при следующем запуске, закройте DSH и откройте снова.
6. **Settings → General → Language → Русский**.

## Удаление

Плагины → dsh-locale-ru → Удалить.
